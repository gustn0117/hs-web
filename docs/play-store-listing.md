## 데이터 보안 양식 답안

Play Console → 정책 → 앱 콘텐츠 → 데이터 보안. 아래대로 답한다.

### 수집·공유 여부

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하는가 | **예** |
| 전송 중 암호화되는가 | **예** (전 구간 HTTPS) |
| 삭제를 요청할 수 있는가 | **예** (앱 「내 정보」에서 직접 탈퇴) |
| 제3자와 공유하는가 | **아니요** |

### 수집 항목

| 분류 | 항목 | 목적 | 필수 |
|---|---|---|---|
| 개인 정보 | 이름 | 앱 기능 | 필수 |
| 개인 정보 | 사용자 ID | 앱 기능, 계정 관리 | 필수 |
| 금융 정보 | 구매 내역 | 앱 기능 (청구 내역 표시) | 필수 |
| 앱 활동 | 앱 내 상호작용 | 앱 기능 | 선택 |
| 기기 ID | 기기 또는 기타 ID | 앱 기능 (푸시 알림 전송) | 선택 |

**수집하지 않는 것**: 위치, 연락처, 사진·동영상, 파일, 캘린더, 통화 기록,
문자, 건강·피트니스, 음성, 주소록, 검색 기록, 설치된 앱 목록.
광고 식별자도 쓰지 않는다.

## 심사용 설명 (Play Console 에는 애플 같은 「심사 노트」 칸이 없다)

구글은 따로 노트 칸을 주지 않는다. 대신 비공개 테스트 트랙 설명과
데이터 보안 설명 문구에 아래를 녹인다. 테스터 계정은 아래를 쓴다.

```
Demo account — ID: test / Password: 1234
```

이 계정에는 예시 프로젝트·결제·도메인이 들어 있어 모든 탭에 내용이 보인다.

### 구조를 먼저 밝힌다

이 앱은 Capacitor 로 감싼 하이브리드 앱이고, 화면은
`https://haonlabs.com/client/dashboard` 에서 실시간으로 받아 온다.
푸시 알림, 지문·얼굴 인증, 햅틱, 네이티브 상태바·키보드 처리는
네이티브로 돈다. 숨긴 기능도, 심사 감지도, 원격 스위치도 없다.

같은 도메인에 공개 홈페이지와 직원 전용 관리자 영역(`/admin`)이 있다.
관리자는 고객 계정과 완전히 다른 인증을 쓰고, 앱 안에서 그쪽으로 가는
링크는 없다. 애플 심사 노트에도 같은 내용을 적어 뒀다.
